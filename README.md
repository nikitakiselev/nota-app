# Nota

Голосовой ввод для macOS. Удерживаете клавишу, говорите, отпускаете —
распознанный текст появляется в активном окне.

Нота — придуманный людьми способ записать звук значками. Nota делает
ровно это, только значки — буквы.

## Что умеет

- **Распознавание идёт на вашем компьютере.** whisper.cpp с моделью
  large-v3 на Apple Silicon. Ни один байт речи не уходит в сеть.
- **Понимает русскую речь с английскими терминами** — gcloud, BigQuery,
  terraform, PostgreSQL. Ради этого приложение и сделано.
- **Промолчали — ничего не вставится.** Перед распознаванием запись
  проверяет детектор речи: если в ней только тишина, шум или фоновая
  музыка без слов, модель не запускается и не сочиняет фраз вроде «Продолжение следует…».
- **Четыре слоя коррекции терминов.** Список терминов подсказывается
  модели до распознавания; точные правила чинят устойчивые искажения;
  фонетическое сопоставление ловит «кубернетес» → Kubernetes; при желании
  текст дополнительно правит внешняя модель по OpenAI-совместимому API.
- **Индикатор уровня записи** с зонами и подсказками «тихо, говорите
  громче» — пороги подобраны замером, при каком уровне модель начинает
  терять термины.
- **Статистика**: сколько слов надиктовано, темп речи, сколько времени
  сэкономлено против набора руками.

Каждое правило проверяется на живом тексте прямо в окне настроек: вставьте
распознанную фразу и увидите, что с ней сделают ваши правила.

## Требования

- macOS 15 или новее
- Apple Silicon (M1 и новее)
- ~1.5 ГБ оперативной памяти, пока приложение запущено
- Модель (~1 ГБ) скачивается при первом запуске

## Установка

Приложение не подписано сертификатом Apple для распространения, поэтому
скачивание через браузер macOS заблокирует. Установите командой — так
файл не помечается карантином:

```sh
curl -L https://github.com/nikitakiselev/nota-app/releases/latest/download/Nota.zip -o /tmp/Nota.zip
unzip -q /tmp/Nota.zip -d /Applications
open /Applications/Nota.app
```

Если уже скачали через браузер, снимите карантин вручную:

```sh
xattr -dr com.apple.quarantine /Applications/Nota.app
```

При первом запуске приложение попросит доступ к микрофону и к
универсальному доступу — без второго не работают ни горячая клавиша, ни
вставка текста.
