# Лендинг Nota

Статический сайт без сборки: `index.html` + `css/style.css` + `js/main.js`.
Стили — Tailwind CSS (CDN, play-режим, конфиг прямо в `index.html`), карусель
скриншотов — Swiper (CDN), шрифты — Google Fonts. Все пути в HTML
относительные — сайт можно раздавать откуда угодно, в том числе с GitHub
Pages как `username.github.io/repo/`.

## Как посмотреть

Открыть `index.html` в браузере (`file://…`) или поднять любой статический
сервер из каталога `landing/`, например:

```bash
python3 -m http.server 8765
# затем http://localhost:8765/
```

## Перед публикацией — заменить

- **Ссылка на скачивание.** Площадка для продажи ещё не выбрана. Кнопки
  «Скачать» заменены на неактивную плашку «Скоро в продаже» (шапка,
  мобильное меню, hero) — рядом в hero и в футере есть `mailto:` со
  строкой «Напишите, если хотите узнать о выходе». Когда площадка
  появится, плашки нужно заменить на настоящую ссылку на страницу продажи
  (или на `.dmg`/`.zip`) — вручную, кнопки сейчас не `<a href>`, а `<span>`.
- **Иконки.** Больше не заглушка: `assets/icons/` — копия
  `misc/icons/web/` (favicon-16/32, apple-touch-icon, og:image, лого в
  шапке и футере). При замене исходников иконок в `misc/` не забудьте
  скопировать их сюда заново.
- **Почта.** Больше не заглушка: `kiselev2008@gmail.com` — в футере, в
  hero-плашке «Напишите, если хотите узнать о выходе» и в `mailto:`.
- **Скриншоты окна настроек** — семь штук, уже на месте в
  `assets/screenshots/` (`settings-*@2x.png`). Каждый показывается в
  естественных пропорциях на фиксированную высоту (CSS `clamp()`), без
  обрезки — окно настроек у разных вкладок разной высоты, это нормально.

## Недостающие скриншоты

Два кадра в карусели «Интерфейс» всё ещё заглушки — владелец снимет их
отдельно (это не окно настроек, а мимолётные UI-состояния). Класть в
`landing/assets/screenshots/` строго под этими именами (PNG, 2x Retina —
указанный размер уже с учётом плотности); как только файл появится —
заглушка исчезнет сама, без правки HTML:

| Файл | Размер | Что снять |
|---|---|---|
| `menubar-dropdown.png` | 320×420 | Открытое меню значка в менюбаре (вертикальный кадр) |
| `status-panel.png` | 560×160 | Плавающая панель уровня записи поверх окна, в момент диктовки (по возможности — с заметным пиком в жёлтой/красной зоне, чтобы были видны все цвета шкалы) |

Снимать на светлой системной теме — под неё сделан весь лендинг.

## Структура блоков

1. **Шапка** — иконка + название, якорные ссылки, плашка «Скоро в продаже», мобильное меню.
2. **Hero** — обещание + мокап панели уровня записи и «печатающейся»
   коррекции термина поверх окна терминала.
3. **Происхождение имени** — короткая цитата про Nota / ноту как способ
   записать звук значками.
4. **Приватность** (`#privacy`) — три карточки: офлайн-распознавание, сеть
   только для загрузки весов, постобработка как единственное явное
   исключение.
5. **Коррекция терминов** (`#layers`) — четыре слоя коррекции как конвейер:
   подсказка декодеру → точные замены → фонетический словарь →
   постобработка.
6. **Скриншоты интерфейса** (`#screenshots`) — карусель Swiper: семь реальных
   кадров окна настроек + две заглушки для мимолётных UI-состояний
   (см. таблицу выше).
7. **Индикатор уровня** (`#meter`) — разбор зон дБФС и порога −26 дБФС из
   замера.
8. **Статистика** (`#stats`) — иллюстративный график + карточки метрик
   (данные на макете вымышленные, помечены как иллюстрация).
9. **Футер** — иконка, контакт (реальная почта), системные требования,
   плашка «Скоро в продаже», копирайт.

## Технические заметки

- Никакого npm/сборки: Tailwind и Swiper — через `<script src="https://cdn…">`.
- Палитра и радиусы — CSS-переменные в `css/style.css`, подключены в
  `tailwind.config` внутри `index.html` (`bg-violet`, `text-mint` и т. д.).
- Анимации появления блоков — `IntersectionObserver` в `js/main.js`,
  уважают `prefers-reduced-motion` (и через JS-проверку, и через
  `motion-safe:`-варианты Tailwind в разметке).
- Прогресс-бар прокрутки вверху страницы залит тем же зелёно-жёлто-красным
  градиентом, что и индикатор уровня записи в приложении, — сквозной мотив
  лендинга.
